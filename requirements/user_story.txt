### USER STORY ###
UserStory: As a user, I want to order Biryani from a food delivery app by applying filters such as restaurant distance, rating, and discount availability so that I only see the best nearby value-for-money options.

Description: The system should allow the user to search for 'Biryani' and automatically filter the restaurant results based on three mandatory criteria: Restaurant must be within 5 km radius from the user location.

### ACCEPTANCE CRITERIA ###
AC1: Filtered Results Display ,Given the user has set a valid delivery location,And searches for 'Biryani',When the system fetches restaurant results,Then only restaurants that satisfy all conditions below must be shown: Distance within 5 km
